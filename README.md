# Ottimizzatore Divisione Squadre
Applicazione web interattiva sviluppata in Python e Streamlit nell'ambito del corso di Ingegneria del Software presso l'Università degli Studi di Udine.

Il software permette di calcolare la suddivisione ottimale di un gruppo in due squadre attraverso un'analisi combinatoria esaustiva di tutte le combinazioni possibili, massimizzando il punteggio medio complessivo.
L'applicazione consente l'importazione dei dati tramite file .csv strutturati e offre un'interfaccia grafica dotata di un'anteprima tabellare dei dati e di riquadri dedicati alla visualizzazione dei risultati finali, risultando accessibile anche direttamente via web.
